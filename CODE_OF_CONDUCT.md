# Código de conduta

Este é um espaço para aprender e ensinar japonês e para construir um app juntos. Para que continue assim:

## O que esperamos

- Tratar todo mundo com respeito, qualquer que seja o nível de japonês, de programação ou de experiência.
- Criticar o texto, o código ou a ideia, nunca a pessoa.
- Receber correções com boa vontade: o conteúdo daqui foi escrito com ajuda de IA e **vai** ter erros. Apontá-los é contribuir.
- Dar contexto ao relatar um problema (aparelho, versão, passo a passo) e ter paciência: o projeto é mantido por uma pessoa.

## O que não é aceito

- Assédio, insultos, discriminação ou ataques pessoais.
- Publicar dados pessoais de outras pessoas.
- Spam, propaganda e conteúdo que nada tem a ver com o projeto.
- Insistir depois que alguém pediu para parar.

## O que acontece

Quem mantém o projeto pode editar ou apagar comentários, issues e pull requests que fujam disso, e bloquear quem continuar. Para relatar um comportamento, use o **relato privado** da aba [Security](https://github.com/EdineiMZ/Moji-Dojo/security) do repositório, ou marque a pessoa responsável pelo repositório numa issue, se não for algo sensível.

Este código de conduta vale para as issues, os pull requests, as discussões e qualquer espaço público em nome do projeto.
